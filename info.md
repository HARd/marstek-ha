# Marstek Energy System & Battery (Home Assistant Integration)

Повнофункціональна інтеграція Home Assistant для енергетичних систем та акумуляторних батарей **Marstek** (серії Venus C/E, Venus D/A та інші) за локальним протоколом **Marstek Open API Rev 2.0 (LAN / UDP)**.

Включає підтримку автоматичного виявлення пристроїв у локальній мережі, відслідковування наявності напруги електромережі, роботи резервного живлення (Off-grid / UPS), статусу зарядки, а також керування режимами роботи, глибиною розряду (DOD) та LED-індикацією.
